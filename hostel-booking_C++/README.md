# Управление хостелом: ООП на C++

Консольное приложение для управления хостелом на C++ с применением
объектно-ориентированной парадигмы. Проект реализует учёт номерного фонда,
бронирование мест, расчёт стоимости проживания и статистику загрузки.

## Возможности

- Добавление и удаление комнат (общие и частные)
- Заселение гостей с проверкой доступности мест по датам
- Расчёт стоимости проживания (полиморфный — для общих и частных комнат разные формулы)
- Просмотр занятости всех комнат на текущую дату
- Статистика загрузки и список гостей
- Защита от некорректного ввода и двойных бронирований

## Архитектура

- **Наследование:** абстрактный класс `Room` → `SharedRoom`, `PrivateRoom`
- **Полиморфизм:** виртуальный метод расчёта стоимости для разных типов комнат
- **Инкапсуляция:** закрытые атрибуты, доступ через методы
- **Композиция:** класс `Hostel` управляет коллекциями комнат и гостей

## Стек

- C++ (STL)
- UML-диаграмма классов
