# Автоматизация процессов учёта и списания материальных ценностей на складском предприятии

Учебный проект по практике от индустриальных партнёров (SILA Union, BPMSoft, Visiology).
Моделирование, автоматизация и аналитика складских операций на примере оптового мебельного склада.

## О проекте

**Предметная область:** оптовый склад мебельной продукции.

**Задача:** автоматизировать процесс учёта и списания товарно-материальных ценностей (ТМЦ) — от моделирования бизнес-архитектуры до BI-аналитики.

Проект реализован на трёх платформах:
| Платформа | Назначение | Что сделано |
|-----------|-----------|-------------|
| SILA Union | Моделирование бизнес-архитектуры | 3 диаграммы: оргструктура, VAD-карта процессов, EPC-декомпозиция |
| BPMSoft | Автоматизация бизнес-процессов | Информационная структура, бизнес-процесс согласования заявок, дашборды |
| Visiology | BI-аналитика | Дашборд с 6 виджетами на основе собственных данных |

## Диаграммы (SILA Union)

### 1. Организационная структура
Иерархия управления складом: от генерального директора до рядовых сотрудников.
Распределение зон ответственности по 8 подразделениям.

### 2. Верхнеуровневая карта процессов (VAD)
Разделение процессов на основные, управленческие и вспомогательные.
Точка синхронизации — процесс «Учёт и списание материальных ценностей».

### 3. Декомпозиция процесса списания ТМЦ (EPC)
Последовательность действий, событий и документов при списании.
Включает цикл «проверка → замечания → доработка», шлюзы «ИЛИ»,
точки интеграции с BPMSoft и Visiology.

## Бизнес-процесс (BPMSoft)

### Схема процесса согласования заявок
Полный цикл: создание заявки → заполнение → согласование →
одобрение/возврат → списание → обновление остатков.

### Дашборды BPMSoft
- **Перемещения по складу:** стоимость перемещений по товарам, статус выполнения
- **Материальные активы:** количество и стоимость по категориям, детальный перечень

## BI-дашборд (Visiology)

Дашборд «ЭМУСА — Мебельный склад» построен на данных,
самостоятельно подготовленных в Excel (4 таблицы: сотрудники, активы, ячейки, заявки).

Виджеты:
- Общая статистика (82 актива)
- Количество сотрудников по отделам
- Вместимость ячеек склада (А1–В3)
- Доля товаров в общей стоимости (круговая диаграмма)
- Суммы списания по заявкам
- Таблица сотрудников
